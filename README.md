# Lab 9 - Using Your Functions

This lab is open-ended. The tests only check your header and comments. You
decide whether your program uses its functions well, using the lesson as your
guide.

Open `main.py` and complete the following:

1. Update the header with your information (Name, Purpose, Author, Created, Updated).
2. Copy all three functions from your Lab 8 `main.py` (`miles_to_km`, `time_in_seconds`, `letter_count`) to just below the header. Do not copy Lab 8's main program.
3. Below the functions, write a short program that uses at least one of the functions several times, with different parameters, for different results.
4. Use if statements and loops where they make sense.
5. Store each returned value in a variable and do something with it (compare it, add it up, print a message based on it).

**Exceeding Expectations:** check whether a function gave back `None`. If it
did, your program should not carry on as usual.

## Running your program

Open `main.py` and press the Run button in the top right corner of VS Code. Your output appears in the terminal at the bottom.

## Checking your work

Press **Ctrl+Shift+B** to run the tests. You will see one line per test:

```
[PASS] 1. Header is filled in
[FAIL] 2. Code is commented
```

When a test fails it shows what it expected. Fix your code and press Ctrl+Shift+B again. Keep going until all tests pass, then check your program against the lesson yourself.

## Reminders

- Fill in every field of the header before you write any code.
- Write comments as you go, in the functions and in the main program.
- Calling a function once, or calling it the same way inside a loop, misses the point. Each call should do something different.
